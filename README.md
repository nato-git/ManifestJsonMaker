# ManifestJsonMaker

マインクラフト統合版でアドオンを開発する際に必要なmanifest.jsonを自動で生成してくれるプログラムです。

## 使用方法

このリポジトリをダウンロードしてindex.pyを実行してください。
作成するアドオンの名前とその説明、UIとリソースパックの有無を入力することでmanifest.jsonが作成されます。

## 注意

デフォルトではプログラム名はindex.jsになっていますお好みで変更してください。  
使用するバージョンなどは自分で変更してください。現在はminecraft/serverが 2.9.0 、minecraft/server-uiが 2.1.0 になっています。(随時更新予定)
